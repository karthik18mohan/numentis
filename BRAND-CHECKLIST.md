# Numentis web QC checklist (from Brand Manual, 24 chapters)
Source facts/wording: client folder Numentis_Website_Preview (layout NOT reused).

## Identity (ch 02-04, 11)
- [L1] Logo = official Skills Lab lockup SVG, byte-identical to pack (horizontal ink on light, horizontal white / stacked white on dark). Never re-typeset.
- [L2] Logo width >= 80px everywhere; clear space >= cap-height of n on all sides.
- [L3] No tagline/descriptor inline with wordmark; wordmark lowercase; dot always terracotta.
- [L4] Favicon = terracotta rounded-square "n." (32px min); apple-touch-icon 180+.
- [L5] Vertical name in Fraunces italic only (lockup file), "Numentis" never in Fraunces italic.
- [L6] Four verticals listed alphabetically, equal weight: Audit & Advisory, Next, Skills Lab, Strategy & Finance.
## Colour (ch 05-07)
- [C1] Only #C2410C #0F1419 #FAFAF7 #F5F1EA #6B6F76 (+ alpha tints of ink/paper). No Forest, no blue/gold/teal, no other hex.
- [C2] Terracotta exactly #C2410C, never gradiented/lightened/tinted. One accent per layout.
- [C3] Terracotta used for: CTA buttons, italic keyword in headings, accent rules. Never as dot/bullet/indicator/separator. No round terracotta shapes.
- [C4] Themes: Atelier Light default (~70%); Atelier Dark only hero + footer; Cream for alternating sections; no Forest.
- [C5] Bullets/separators in Mute Grey or em dash, not terracotta dots.
## Type (ch 08, 8.1)
- [T1] Only Fraunces, Onest, JetBrains Mono (+ Familjen only inside logo files).
- [T2] body: Onest 15px/400/lh1.5/ls -0.01em, #0F1419.
- [T3] h1,h2: Fraunces 400, lh 1.05, ls -0.03em, opsz 144.
- [T4] labels/eyebrows/numerics: JetBrains Mono, 11px, ls .18em, uppercase (labels). Numbers/codes in mono.
- [T5] Italics (Fraunces) only for emphasis words + tagline; tagline "Where numbers think." / "From degree to desk." Fraunces italic.
## Voice (ch 09)
- [V1] No synergy/leverage/paradigm/ecosystem/journey/world-class/best-in-class/premium quality.
- [V2] No exclamation marks, no emoji.
- [V3] Plain, short sentences; rupee as ₹50,000; dates DD Month YYYY; percentages no space.
- [V4] Position statement verbatim on site.
## Imagery (ch 10)
- [I1] No stock, no people, no literal finance imagery. Texture only (paper/ruled lines/grain).
## Web (ch 07, 08.1, 23)
- [W1] Website default Atelier Light; homepage hero Atelier Dark.
- [W2] Web-safe fallback stacks (Georgia / system-ui).
- [W3] AA contrast; keyboard nav; alt text; reduced-motion respected; no horizontal scroll 360-1440.
- [W4] Skills Lab copy matches manual 11.1 + client folder facts (4 months, 6 modules, in person Calicut, practitioners, hiring orgs, Rs 50,000).
- [W5] No invented facts (no fake numbers, names, phone, email, batch dates).
